## Rules of the game

1. **Real work only** — no empty commits; every day ships something reviewable.
2. **Small PRs** — one task = one PR = fast merge.
3. **Green CI always** — a red badge kills trust.
4. **Docs grow with code** — no feature without README/test updates.
