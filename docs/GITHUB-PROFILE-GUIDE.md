## 4. What recruiters actually check

1. Pinned repos with great READMEs (screenshots, setup, demo).
2. Green, *believable* graph: code + reviews + issues, not 50 commits/day.
3. Merged PRs, releases, and helpful issue replies.
4. A profile README that says what you build and where you're going.

> Quantity opens the door, **quality gets the interview**. Ship daily,
> but keep every day reviewable.
